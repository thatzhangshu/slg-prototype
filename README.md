# SLG Map Demo

基于 Unity 开发的 SLG 地图原型，围绕地图生成、分块渲染、地块交互与行军玩法持续迭代。后续将整合独立开发的 UIFramework，逐步形成可运行、可演示的 SLG Demo。

## 当前阶段

项目处于地图原型阶段，已提交 GitHub 进行版本管理。当前主要验证程序化格子地图、Chunk Mesh 和基础交互，后续逐步完善连续地表与 SLG 玩法。

## 迭代计划

- [ ] 分离地图数据、生成、渲染与输入职责
- [ ] 实现连续起伏地表，处理 Chunk 边界与法线接缝
- [ ] 完善地表拾取、贴地高亮与相机控制
- [ ] 增加资源类型、地块等级、归属与产出配置
- [ ] 添加资源模型与基础地表材质
- [ ] 整合 UIFramework，实现地块详情与操作面板
- [ ] 实现路径预览、行军与占领流程
- [ ] 完善动态加载、对象复用与性能分析

## 首个可玩目标

完成“选择资源地 → 查看详情 → 预览路线 → 派兵行军 → 到达占领 → 更新归属与产出”的操作流程。

地图业务数据独立于 Chunk 显示生命周期，确保镜头移动、Chunk 回收与重建后，地块状态保持一致。

## 开发方式

采用小步迭代，每个阶段完成一组可验证的功能，并记录关键设计取舍与性能测试结果。
