# SLG 方块地图第一阶段原型

## 运行

打开 `Assets/Scenes/SLGPrototype.unity`，点击 Play。

- 中键拖拽或 `Alt + 左键`：平移地图
- 鼠标滚轮：缩放
- 左键：选择格子
- `R`：按当前种子重新生成
- `F5`：保存地图
- `F9`：读取地图

## 架构

- 地图数据：紧凑的 `byte[]`，256×256 只占约 128 KB；可扩展到 2048×2048。
- 渲染：每个 `16×16` 格子构建为一个合并 Mesh，按视野动态加载。
- 对象池：离开视野的分块会进入池中并复用。
- 格子类型：山地、水域、城池、普通土地、木材、粮草、石头、铁矿。
- 存档位置：`Application.persistentDataPath/slg_map_save.json`。
